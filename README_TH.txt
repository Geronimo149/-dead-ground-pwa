DEAD GROUND PWA v0.2 — คู่มือภาษาไทย

สิ่งที่มีในรุ่นนี้
- หน้าภาพรวมสถานะ วัน เวลา สถานที่ สถานการณ์ และแผนถัดไป
- ฐานข้อมูลสมาชิกค่าย/NPC, ทรัพยากรและยานพาหนะ, ข่าวกรอง และบันทึกเหตุการณ์
- บันทึกอัตโนมัติในเบราว์เซอร์ของอุปกรณ์นี้
- ส่งออก/นำเข้าไฟล์เซฟ JSON เพื่อสำรองหรือย้ายอุปกรณ์
- สร้างข้อความสถานะสำหรับคัดลอกไปให้ ChatGPT GM
- โครงสร้าง PWA พร้อม manifest, ไอคอน SVG และ Service Worker สำหรับแคชไฟล์เพื่อใช้ออฟไลน์
- ไม่มีรูปตัวละครหรือรูปค่าย และไม่มีการเชื่อมต่อ AI/API

ข้อจำกัดสำคัญ
1. ข้อมูลยังเก็บเฉพาะในเบราว์เซอร์และอุปกรณ์ที่เปิดใช้งาน ไม่ซิงก์อัตโนมัติระหว่างมือถือกับคอมพิวเตอร์
2. การล้างข้อมูลเว็บไซต์/เบราว์เซอร์อาจลบเซฟในเครื่อง จึงควรดาวน์โหลดไฟล์ JSON สำรองสม่ำเสมอ
3. PWA ต้องโฮสต์ผ่าน HTTPS (เช่น GitHub Pages) หรือ localhost จึงจะติดตั้งและแคชออฟไลน์ได้ การเปิด index.html ตรงจาก ZIP/file:// ใช้หน้าจอได้ แต่ติดตั้ง PWA และ Service Worker ไม่ทำงาน
4. การใช้งานออฟไลน์ครั้งแรกต้องเปิดผ่าน HTTPS และโหลดแอปให้เสร็จก่อน

เริ่มทดลอง
- แตกไฟล์ ZIP แล้วเปิด index.html เพื่อทดลองฟังก์ชันพื้นฐานได้ทันที
- หากต้องการติดตั้งจริงบน Android/คอมพิวเตอร์ ให้อัปโหลดเนื้อหาในโฟลเดอร์นี้ขึ้นโฮสต์ HTTPS แบบ static จากนั้นเปิด URL ใน Chrome/Edge แล้วเลือกเมนู Install app / เพิ่มไปยังหน้าจอหลัก
- หากย้ายเครื่อง: ในเครื่องเก่ากด เซฟ/โหลด > ดาวน์โหลดไฟล์เซฟ; ในเครื่องใหม่เปิดแอป > นำเข้าไฟล์เซฟ แล้วเลือกไฟล์ JSON

ข้อมูลเริ่มต้นตั้งต้นจากสถานะ DEAD GROUND ที่มีอยู่ในต้นแบบเดิม ณ 28 ตุลาคม เวลา 19:50 โดยแผนวันที่ 29 ตุลาคมยังเป็นแผน ไม่ใช่เหตุการณ์ที่เกิดขึ้นแล้ว
